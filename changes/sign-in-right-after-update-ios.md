testflight: Continue with Google or GitHub right after an install or update opens sign-in on the first tap; while it waits, the status offers Cancel.
platforms: [ios]
order: 22
---
Right after you installed or updated Spoonjoy, the first tap on Continue with Google or GitHub could close the sign-in before anything appeared, so you had to tap again. Spoonjoy now keeps trying by itself for up to half a minute while the status reads Opening sign-in, with a Cancel button if you change your mind, so one tap is enough. If sign-in still can't open, it says so and asks you to try again.
