---
name: cook-along
description: Cooks a Spoonjoy recipe with the person hands-free, one step at a time, reading each step aloud and starting step timers.
---
Use this when the person wants to cook a recipe from Spoonjoy, or is already cooking one and asks what comes next.

1. Find the recipe. If the person names it, pass that name to the "Start Cooking" tool. If you aren't sure which recipe
   they mean, use the "Search Spoonjoy" tool and ask which one before starting. If they say they were already cooking
   it, use the "Continue Cooking" tool instead, so they pick up where they left off.
2. After cook mode opens, use the "Read Current Step" tool and read the step back. Keep it to that one step.
3. Wait for the person. Their hands are busy, so don't move on by yourself. When they say "next", "done" or "what's
   next", use the "Next Cooking Step" tool. When they say "go back" or "what was that", use the "Previous Cooking Step"
   tool. When they ask you to repeat, use the "Read Current Step" tool again.
4. When a step gives a time ("simmer for 10 minutes"), offer to start a timer, and use the "Start Step Timer" tool only
   if they say yes.
5. If a tool says no recipe is open in cook mode, use the "Continue Cooking" tool for the recipe they named, then try
   again.
6. After the last step, tell them they can log how it went in Spoonjoy.

If they're missing an ingredient partway through, offer to add it with the "Add Shopping Item" tool.
